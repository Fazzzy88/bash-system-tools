# Bash System Tools & Automation Scripts 🛠️

Коллекция Bash-скриптов для автоматизации системного администрирования Linux, первичной настройки серверов, создания резервных копий и мониторинга.

## Содержание репозитория

| Скрипт | Описание | Основные функции |
| :--- | :--- | :--- |
| `server-hardening.sh` | Первичная настройка и защита VPS/сервера | Настройка UFW, загрузка SSH-ключей, отключение root-пароля, установка базового ПО |
| `backup-rotation.sh` | Резервное копирование директорий / БД | Архивация, сжатие, отправка в удаленное хранилище, ротация старых бэкапов |
| `system-cleanup.sh` | Чистка дискового пространства | Очистка логов, кэша пакетного менеджера (apt/pacman), неиспользуемых Docker-образов |

---

## Особенности реализации

- **Безопасное выполнение:** Все скрипты используют строгий режим `set -euo pipefail` (остановка при ошибках и необработанных переменных).
- **Логирование:** Поддержка цветного вывода в консоль и запись всех действий в `/var/log/system-tools.log`.
- **Идемпотентность:** Повторный запуск скриптов не ломает существующую конфигурацию.

- **Права:** `sudo` / `root`
